# LoveTweaks

Коллекция механик и контента для RPG: Глашатай, Почта, стартовый набор и другие улучшения.

## Общая структура

LoveTweaks предоставляет набор специализированных фич, объединённых под одним плагином:

- **Королевский Глашатай** — NPC для покупки объявлений, которые будут транслироваться в чат каждые N часов
- **Королевская Почта** — NPC Почтмейстер для отправки посылок. Почтовый голубь летит от отправителя к получателю, его можно сбить стрелой
- **Стартовый набор** — выдаётся один раз при первом заходе на сервер
- **Иные твики** — отключение менда, потеря предметов при выбрасывании, регулировка голода и т.д.

## Команды

| Команда | Описание | Пермишин |
|---|---|---|
| `/lovetweaks` | Администраторские команды | `lovetweaks.admin` |
| `/lovetweaks reload` | Перезагрузить конфигурацию | `lovetweaks.admin` |
| `/lovetweaks givescroll <игрок>` | Выдать свиток телепортации к игроку | `lovetweaks.admin` |
| `/lovetweaks givecoordscroll <игрок>` | Выдать свиток телепортации по координатам в мире `world` | `lovetweaks.admin` |
| `/lovetweaks herald bind` | Привязать NPC Глашатая (смотреть на NPC) | `lovetweaks.admin` |
| `/lovetweaks herald unbind` | Отвязать NPC Глашатая | `lovetweaks.admin` |
| `/lovetweaks herald clear` | Очистить все объявления | `lovetweaks.admin` |
| `/lovetweaks herald open [игрок]` | Открыть меню Глашатая | `lovetweaks.admin` |

## Конфигурация

### Основные механики

```yaml
ender-chests:
  as-normal-chests: true  # обращение с эндер-сундуками как с обычными

enchantments:
  disable-mending: true   # отключить мендинг
  disable-all-enchantments: false  # отключить все зачарования

hunger:
  extra-exhaustion-per-second: 0.25  # дополнительное истощение голода
  saturation-multiplier: 0.5         # множитель сытости при еде

milk:
  disable-milk: true  # отключить молоко (не очищает эффекты)

brewing:
  disable-brewing: true               # отключить варку любых зелий в варочной стойке
  disable-brewing-stand-craft: true   # отключить крафт варочной стойки
  disable-brewing-stand-world: true   # удалить варочные стойки из мира (генерация, сундуки, установка)
  disable-potion-natural-drops: true  # отключить естественное появление и выпадение зелий (сундуки, ведьмы, бартер, рыбалка)
  disabled-message: '&cЗельеварение и варочные стойки отключены на этом сервере.'
```

### Потеря предметов при выбрасывании

```yaml
item-drop-loss:
  enabled: true
  lose-chance: 0.22      # вероятность потери обычного предмета
  break-chance: 0.33     # вероятность поломки предмета с durability
```

### Свиток телепортации к координатам

Свиток для свободной телепортации по координатам в основном мире (`world`).
ПКМ со свитком запускает 10-секундный ввод координат в чат (формат `X Z` или `X Y Z`).
После ввода запускается 5-секундный отсчёт (отменяется движением/невидимостью/PvP/выбрасыванием свитка), после чего игрок телепортируется на указанную точку. Выдаётся командой:
`/lovetweaks givecoordscroll <игрок>`.

```yaml
coord-teleport-scroll:
  enabled: true
  target-world: 'world'
  cast-time-seconds: 5      # отсчёт перед телепортацией
  cooldown-seconds: 30      # кулдаун повторного использования
  limits:
    min-y: -64                    # ниже — телепортация запрещена
    max-y: 320                    # выше — телепортация запрещена
    respect-world-border: true    # точка обязана быть внутри world border
    max-distance-from-spawn: 0    # 0 = не ограничивать; иначе макс. блоков от спавна мира
    allowed-worlds:
      - 'world'
```

Лимиты `limits` проверяются при вводе координат и перед самой телепортацией.

### Королевский Глашатай

```yaml
herald:
  enabled: true

  # Ключ NPC LoveEssential (ext-xxxxxxxx, имя или номер), привязывается командой /lovetweaks herald bind
  npc-key: ''
  npc-name: ''

  # Стоимость объявления (в монетах LoveCore)
  cost: 500

  # Интервал трансляции объявления
  broadcast-interval-hours: 2

  # Заголовок GUI
  gui-title: '&6⚡ Королевский Глашатай'
```

Объявления можно купить, взаимодействуя с NPC Глашатаем. После покупки объявление будет транслироваться в чат сервера каждые `broadcast-interval-hours` часов в течение 24 часов. Максимум 3 объявления одного игрока одновременно.

### Королевская Почта

```yaml
post:
  enabled: true

  # Ключ NPC LoveEssential, привязывается командой /lovetweaks post bind
  npc-id: -1
  npc-name: ''

  # Стоимость отправки посылки (в монетах LoveCore)
  cost: 200

  # Время полёта голубя от отправителя к получателю
  flight-seconds: 20

  # Заголовок GUI
  gui-title: '&6✉ Королевская Почта'

  # Вероятность сбива голубя в час враждебной территории
  # Требует LoveCore с TerritoryOracle (LoveClaims)
  hostile-territory-shootdown-chance-per-tick: 0.0035
```

**Механика**: Игрок кладёт предметы в интерфейс Почты, указывает получателя, платит. Почтовый голубь физически летит от отправителя к последнему известному месту получателя. Голубя можно сбить стрелой в полёте (посылка выпадет на землю). Если маршрут проходит через враждебную территорию (LoveClaims), вероятность сбива повышается.

**Примечание**: Без LoveCore TerritoryOracle голубь летит с нулевым риском (враждебные территории не учитываются).

### Стартовый набор

```yaml
first-join:
  enabled: true
  items:
    # Телепортационный свиток (материал/имя/описание игнорируются)
    - material: PAPER
      teleport-scroll: true
      amount: 1
    
    # Обычный предмет с кастомным именем
    - material: IRON_SWORD
      amount: 1
      display-name: '&aНачальный меч'
      lore:
        - '&7Ваш первый меч на сервере'
    
    # Простой предмет
    - material: COOKED_BEEF
      amount: 16
```

Выдаётся один раз при самом первом заходе игрока на сервер (отслеживается в БД).

Табло сервера настраивается в LoveEssential.

## Экономика

### Платежи через Глашатая и Почту

Оба сервиса используют единую валюту LoveCore (`LoveEconomy`):

- **Глашатай**: `cost: 500` монет за объявление
- **Почта**: `cost: 200` монет за посылку

Если у игрока недостаточно монет, сервис откажет в обслуживании.

## Примечания

- Объявления Глашатая видны всем игрокам на сервере, даже в оффлайне.
- Посылки Почты привязаны к последнему известному месту получателя; если получатель никогда не был онлайн, посылка не может быть доставлена.
- Голубя можно сбить стрелой только если он находится в зоне враждебной территории (если LoveClaims включен).
- Табло и его настройки находятся в LoveEssential.

## Поздний запуск NPC-провайдера

NPC-провайдер выбирается через LoveCore и проверяется повторно при каждом обращении.
Первые 200 тиков после включения отведены на асинхронную загрузку провайдеров: временное
отсутствие в этот период не печатается как ошибка. В конце ожидания выполняется проверка;
реальное отсутствие или потеря уже работавшего провайдера по-прежнему диагностируется.
После появления LoveEssential интеграция восстанавливается без перезапуска потребителя.
Видимый номер LoveEssential разрешается в постоянный ключ NPC; новые привязки сохраняют
ключ, выданный провайдером.

Сохранённые привязки сравниваются по постоянному ключу; старый видимый номер не
переназначает роль автоматически при повторном использовании номера. Если после
смены провайдера остался числовой псевдоним, используйте штатную команду привязки
ещё раз, выбрав нужного NPC: новый адаптер вернёт его постоянный ключ.


### Единое оформление Love

Глашатай использует головы для элементов меню. Занятое объявление показывает доступную сохранённую текстуру автора; внешние запросы для offline-UUID не запускаются.

Для обновления существующих конфигов установите актуальный LoveCore вместе с этой версией.
Однократная миграция сохраняет исходные YAML рядом с ними как `.pre-style-20261101.bak`.
После обновления можно менять оформление самостоятельно: перезапуск его не сбрасывает.

Поддержка ReviveMe удалена (2026-11-21): механику «ранен/оживление» ведёт только LoveEssential.

## Проверка рывка копья

`/lovetweaksadmin lunge <ник>` снимает 10-секундный отчёт о предмете и событиях
рывка, использования предмета и перемещения. Нужны права `lovetweaks.admin`.
Проверка ничего не разблокирует и автоматически снимает свои обработчики.

## Наковальня и кузнец

`anvil.remove-prior-work-penalty: true` убирает накопительный штраф предыдущих работ
(1 → 3 → 7 → 15 …), в том числе со старого снаряжения. Обычная цена операции в уровнях
опыта, материалы и правила совместимости зачарований остаются ванильными. Предметы
с большим старым штрафом пересчитываются на следующем тике. `false` возвращает
ванильное накопление для последующих работ.

### Создать кузнеца

1. Установите новый `LoveTweaks.jar` и перезапустите сервер. Новые секции `anvil` и
   `blacksmith` автоматически добавятся в существующий `config.yml`.
2. NPC берётся из LoveEssential (других провайдеров нет): убедитесь, что он установлен и включён.
3. Встаньте на место кузнеца и выполните `/lovetweaksadmin blacksmith create`.
   Для определённого скина: `/lovetweaksadmin blacksmith create НикСкина`.
   Плагин создаст NPC через LoveEssential, сохранит его ключ и привяжет мастерскую.
4. Вместо создания можно выбрать существующего NPC или посмотреть на него и выполнить
   `/lovetweaksadmin blacksmith bind`. Один NPC LoveTweaks не может одновременно быть
   Глашатаем и кузнецом.
5. ПКМ по кузнецу открывает мастерскую. Все административные команды требуют `lovetweaks.admin`.

`/lovetweaksadmin blacksmith unbind` снимает привязку, сохраняя NPC и все заказы.
После переноса или смены провайдера привяжите нового NPC. `/lovetweaksadmin blacksmith open`
открывает администратору его собственный заказ для проверки или восстановления доступа,
если NPC потерян. Обычной команды переносной починки для игроков нет.

### Как игрок сдаёт вещи

- В мастерской 18 слотов для отдельных повреждённых предметов с прочностью. Предмет можно
  положить кликом с курсора или Shift-кликом из инвентаря. Неповреждённые предметы,
  стаки и неразрушимые вещи не принимаются.
- Кнопка показывает общую цену и время. Оплата идёт физическими монетами из инвентаря
  через `LoveEconomy` LoveCore; банковский баланс не используется. Без монет или экономики
  кнопка серая, а повторная проверка при клике не даёт начать неоплаченный ремонт.
- До оплаты предметы можно снять обратно. Кнопка возврата и Shift-клик по предмету
  возвращают весь неоплаченный заказ; закрытие меню тоже возвращает его без ремонта.
- После оплаты предметы остаются у кузнеца до окончания общего времени заказа. Меню
  можно закрыть, выйти из игры и вернуться позже. Повторная оплата и извлечение вещей
  через курсор, Shift, горячие клавиши, двойной клик или перетаскивание блокируются.
- После таймера нажмите «Забрать отремонтированные вещи». При полном инвентаре остаток
  сохраняется у кузнеца; повторное нажатие выдаёт только оставшиеся предметы.
- Ремонт меняет только повреждение предмета. Название, лор, обычные зачарования (включая
  уже существующую «Починку»), кастомные зачарования LoveTweaks, модель, PDC и прочие
  компоненты сохраняются. Это ремонт предметов с прочностью Bukkit/Paper (`Damageable`).

### Цена и время

`blacksmith.prices` задаёт цену полного ремонта в минимальных единицах LoveEconomy
(при стандартной валюте — медные монеты). Приоритет: точный материал в `materials`,
затем префикс в `tiers`, затем `default`.

Цена каждого предмета: `ceil(цена полного ремонта × доля износа ×
(1 + сумма уровней зачарований × enchantment-level-multiplier))`, не меньше `minimum`.
Учитываются ванильные чары и PDC зачарований LoveTweaks, включая их старые ключи.
Затем применяется глобальный `economy.price-index` LoveCore; цены всех предметов складываются.
Например, при стандартных настройках и индексе 1 железный меч с износом 50% стоит
50 медных монет, а с «Остротой V» — 88 медных монет.

Время каждого предмета: `ceil(seconds-per-item × доля износа +
сумма уровней зачарований × seconds-per-enchantment-level)`, не меньше `minimum-seconds`
и одной секунды. Время предметов также складывается. После `/lovetweaksadmin reload`
новые настройки действуют на новые оплаты; цена и срок оплаченного заказа зафиксированы.
`blacksmith.text` содержит название меню и тексты кнопок, подсказок и сообщений.

Заказы хранятся по UUID игрока в `plugins/LoveTweaks/blacksmith.db`, предметы — полными
байтовыми снимками Paper. Таймер использует реальное время, включая время выключенного
сервера. Выход и обычный перезапуск не удаляют оплаченные заказы. Не удаляйте базу, пока
у кузнеца хранятся вещи; для резервной копии остановите сервер и сохраните всю папку LoveTweaks.
`blacksmith.enabled: false` запрещает новые заказы, но позволяет забрать оставленные вещи.
Визуальное поведение NPC и наковальни на живом клиенте следует проверить на тестовом сервере.
