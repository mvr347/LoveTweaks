# LoveTweaks

Коллекция механик и контента для RPG: Глашатай, Почта, стартовый набор и другие улучшения.

## Общая структура

LoveTweaks предоставляет набор специализированных фич, объединённых под одним плагином:

- **Королевский Глашатай** — NPC для покупки объявлений, которые будут транслироваться в чат каждые N часов
- **Королевская Почта** — NPC Почтмейстер для отправки посылок. Почтовый голубь летит от отправителя к получателю, его можно сбить стрелой
- **Стартовый набор** — выдаётся один раз при первом заходе на сервер
- **Иные твики** — отключение менда, потеря предметов при выбрасывании, регулировка голода и т.д.

## Команды

| Команда | Описание | Пермишин |
|---|---|---|
| `/lovetweaks` | Администраторские команды | `lovetweaks.admin` |
| `/lovetweaks reload` | Перезагрузить конфигурацию | `lovetweaks.admin` |
| `/lovetweaks givescroll <игрок>` | Выдать свиток телепортации к игроку | `lovetweaks.admin` |
| `/lovetweaks givecoordscroll <игрок>` | Выдать свиток телепортации по координатам в мире `world` | `lovetweaks.admin` |
| `/lovetweaks herald bind` | Привязать NPC Глашатая (смотреть на NPC) | `lovetweaks.admin` |
| `/lovetweaks herald unbind` | Отвязать NPC Глашатая | `lovetweaks.admin` |
| `/lovetweaks herald clear` | Очистить все объявления | `lovetweaks.admin` |
| `/lovetweaks herald open [игрок]` | Открыть меню Глашатая | `lovetweaks.admin` |

## Конфигурация

### Основные механики

```yaml
ender-chests:
  as-normal-chests: true  # обращение с эндер-сундуками как с обычными

enchantments:
  disable-mending: true   # отключить мендинг
  disable-all-enchantments: false  # отключить все зачарования

hunger:
  extra-exhaustion-per-second: 0.25  # дополнительное истощение голода
  saturation-multiplier: 0.5         # множитель сытости при еде

milk:
  disable-milk: true  # отключить молоко (не очищает эффекты)

brewing:
  disable-brewing: true               # отключить варку любых зелий в варочной стойке
  disable-brewing-stand-craft: true   # отключить крафт варочной стойки
  disable-brewing-stand-world: true   # удалить варочные стойки из мира (генерация, сундуки, установка)
  disable-potion-natural-drops: true  # отключить естественное появление и выпадение зелий (сундуки, ведьмы, бартер, рыбалка)
  disabled-message: '&cЗельеварение и варочные стойки отключены на этом сервере.'
```

### Потеря предметов при выбрасывании

```yaml
item-drop-loss:
  enabled: true
  lose-chance: 0.22      # вероятность потери обычного предмета
  break-chance: 0.33     # вероятность поломки предмета с durability
```

### Свиток телепортации к координатам

Свиток для свободной телепортации по координатам в основном мире (`world`).
ПКМ со свитком запускает 10-секундный ввод координат в чат (формат `X Z` или `X Y Z`).
После ввода запускается 5-секундный отсчёт (отменяется движением/невидимостью/PvP/выбрасыванием свитка), после чего игрок телепортируется на указанную точку. Выдаётся командой:
`/lovetweaks givecoordscroll <игрок>`.

```yaml
coord-teleport-scroll:
  enabled: true
  target-world: 'world'
  cast-time-seconds: 5      # отсчёт перед телепортацией
  cooldown-seconds: 30      # кулдаун повторного использования
  limits:
    min-y: -64                    # ниже — телепортация запрещена
    max-y: 320                    # выше — телепортация запрещена
    respect-world-border: true    # точка обязана быть внутри world border
    max-distance-from-spawn: 0    # 0 = не ограничивать; иначе макс. блоков от спавна мира
    allowed-worlds:
      - 'world'
```

Лимиты `limits` проверяются при вводе координат и перед самой телепортацией.

### Королевский Глашатай

```yaml
herald:
  enabled: true

  # Ключ NPC (id Citizens или ключ LoveEssential), привязывается командой /lovetweaks herald bind
  npc-key: ''
  npc-name: ''

  # Стоимость объявления (в монетах LoveCore)
  cost: 500

  # Интервал трансляции объявления
  broadcast-interval-hours: 2

  # Заголовок GUI
  gui-title: '&6⚡ Королевский Глашатай'
```

Объявления можно купить, взаимодействуя с NPC Глашатаем. После покупки объявление будет транслироваться в чат сервера каждые `broadcast-interval-hours` часов в течение 24 часов. Максимум 3 объявления одного игрока одновременно.

### Королевская Почта

```yaml
post:
  enabled: true

  # ID NPC Citizens, привязывается командой /lovetweaks post bind
  npc-id: -1
  npc-name: ''

  # Стоимость отправки посылки (в монетах LoveCore)
  cost: 200

  # Время полёта голубя от отправителя к получателю
  flight-seconds: 20

  # Заголовок GUI
  gui-title: '&6✉ Королевская Почта'

  # Вероятность сбива голубя в час враждебной территории
  # Требует LoveCore с TerritoryOracle (LoveClaims)
  hostile-territory-shootdown-chance-per-tick: 0.0035
```

**Механика**: Игрок кладёт предметы в интерфейс Почты, указывает получателя, платит. Почтовый голубь физически летит от отправителя к последнему известному месту получателя. Голубя можно сбить стрелой в полёте (посылка выпадет на землю). Если маршрут проходит через враждебную территорию (LoveClaims), вероятность сбива повышается.

**Примечание**: Без LoveCore TerritoryOracle голубь летит с нулевым риском (враждебные территории не учитываются).

### Стартовый набор

```yaml
first-join:
  enabled: true
  items:
    # Телепортационный свиток (материал/имя/описание игнорируются)
    - material: PAPER
      teleport-scroll: true
      amount: 1
    
    # Обычный предмет с кастомным именем
    - material: IRON_SWORD
      amount: 1
      display-name: '&aНачальный меч'
      lore:
        - '&7Ваш первый меч на сервере'
    
    # Простой предмет
    - material: COOKED_BEEF
      amount: 16
```

Выдаётся один раз при самом первом заходе игрока на сервер (отслеживается в БД).

Табло сервера настраивается в LoveEssential.

## Экономика

### Платежи через Глашатая и Почту

Оба сервиса используют единую валюту LoveCore (`LoveEconomy`):

- **Глашатай**: `cost: 500` монет за объявление
- **Почта**: `cost: 200` монет за посылку

Если у игрока недостаточно монет, сервис откажет в обслуживании.

## Зависимости

### Обязательные

- **Paper 1.21.11** — базовый Minecraft сервер

### Мягкие зависимости

- **Citizens** или **LoveEssential** — NPC для Глашатая и Почтмейстера; выбор: `integrations.npc-provider: global|citizens|loveessential` (по умолчанию `global`: как решено в `integrations.provider` LoveCore), доступ через контракт `NpcProvider` в LoveCore
- **ReviveMe** или **LoveEssential** — механика «ранен/оживление»; выбор: `revive.provider: global|reviveme|loveessential` (по умолчанию `global`: как в `integrations.provider` LoveCore; при `loveessential` фиксы ReviveMe не регистрируются)
- **LoveCore** — единая экономика, служба территорий (для риска посылок)
- **PlaceholderAPI** — плейсхолдеры статистики и времени игры
- **ItemsAdder** — кастомные предметы
- **LoveClaims** — территории (влияют на риск сбива голубя)

## Примечания

- Объявления Глашатая видны всем игрокам на сервере, даже в оффлайне.
- Посылки Почты привязаны к последнему известному месту получателя; если получатель никогда не был онлайн, посылка не может быть доставлена.
- Голубя можно сбить стрелой только если он находится в зоне враждебной территории (если LoveClaims включен).
- Табло и его настройки находятся в LoveEssential.

## Поздний запуск NPC-провайдера

NPC-провайдер выбирается через LoveCore и проверяется повторно при каждом обращении.
Первые 200 тиков после включения отведены на асинхронную загрузку провайдеров: временное
отсутствие в этот период не печатается как ошибка. В конце ожидания выполняется проверка;
реальное отсутствие или потеря уже работавшего провайдера по-прежнему диагностируется.
После появления LoveEssential интеграция восстанавливается без перезапуска потребителя.
Видимый номер LoveEssential разрешается в постоянный ключ NPC; новые привязки сохраняют
ключ, выданный провайдером. Число само по себе не означает, что выбран Citizens.

Сохранённые привязки сравниваются по постоянному ключу; старый видимый номер не
переназначает роль автоматически при повторном использовании номера. Если после
смены провайдера остался числовой псевдоним, используйте штатную команду привязки
ещё раз, выбрав нужного NPC: новый адаптер вернёт его постоянный ключ.
